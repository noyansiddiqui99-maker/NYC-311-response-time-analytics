# Raw Data
This folder contains the raw NYC 311 service request data collected from the source API.
The data in this folder is kept in its original form without applying transformations or cleaning. It is used as the input for the Bronze layer of the data pipeline.

## Contents
* Raw data files extracted from the NYC 311 API
* Data files are organized according to the ingestion process
* Original records are preserved for further processing

## Purpose
The raw data is stored separately so that the original source data is available for validation, reprocessing, and comparison with the transformed data in the later stages of the pipeline.
